Automatic calibration

Calibration runs automatically when an event loads. Check the overlay, then Confirm — or Correct manually.

Per-match corner calibrations

Each job checks the corner cameras on its own match and re-solves (and adopts) them when they moved; a corner that can't be verified is dropped from that job. Spot-check the overlays; Reject stops a match's result from being used.

🔧 Auto-fix available — camera pose re-solved

The drift check re-solved the camera pose from AprilTags against the unchanged lens (same distortion). Review the reprojected wireframe + tags below: green boxes are detected tags, cyan boxes are the field model reprojected under the fix — a good fix sits the cyan on the green and the wireframe on the field. Approve saves it as a new calibration version from this match onward; Reject keeps this match flagged so you can calibrate it manually below.

Manual correction — click tags on a frame, solve, and save a version

Grab a frame. Detected tags are outlined in green. For a tag you can see but that wasn't detected: click it on the left frame, then click the matching tag on the right map. The map is oriented to match the camera's view (blue end left, red end right). Add several spread-out tags, then Solve. Need ≥ 8 points (each detected tag = 4 points, each manual tag = 1).

Pick a match when the camera moved mid-event: frames are grabbed from that match's video, and the solved calibration is saved as a new version applying from that match onward (earlier matches keep their old calibration). Matches without a ▶ have no TBA-linked video, so frames fall back to the default test video. ❌ marks matches where the drift check failed for this camera — recalibrate from there. 🔧 marks matches with an auto-fix awaiting your approval (panel appears above).

    Zones & masks — static-element zones, camera exclusion masks, top crop

    Zones are drawn on the top-down map and masks on the broadcast frame — both live in Manual correction, which opens when you tick a draw box.

    Static-element zones — block robot false-positives

    Tick Draw zones, then drag a box on the map around a field element that gets misdetected as a robot (e.g. a fuel structure). A detection inside a zone can never start a new robot track — but a real robot that drives in keeps tracking. Zones are in field coordinates, so one box covers every camera. Remember to Save.

      Camera view exclusion masks — screen out background false-positives

      Tick Draw exclusion masks, then drag a box on the camera view (Broadcast frame) to block out background regions. Detections inside these regions are completely ignored. Remember to Save masks.

        Robot-tracking top crop — disabled, under review

        Currently disabled. Cropping the top airspace would block false positives up there, but because SAM2 resizes every frame to a fixed square it also distorts robot aspect ratio (squished), which may hurt tracking. Parked until we can evaluate that trade-off. The setting still saves, but has no effect on tracking while disabled. (For speed, use the VRAM budget on the main page.)
