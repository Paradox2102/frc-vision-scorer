Putting a team number on each track

The bumper number is the only thing that tells two same-alliance robots apart. Everything else only supports it.

During the match

1Crop the bumpers

Skip a crop when the bumper is hidden in every camera, or the robot hasn't moved since the last read.

2Read the number

Jev picks from only the 3 teams on that alliance, or says "unreadable".

3Vote, lock, re-check

3 agreeing reads lock a team; 2 contradicting reads unlock it. Our embedder keeps the track on the same robot through crossings.

After the match: relabel with hindsight

1Cut every track into short windows

4 s or less, and always cut where the track was lost or jumped, so each window is almost surely one robot.

2Read digits in each window

Our digit reader runs locally and only answers when it's sure.

3Match the rest against a lineup

The sure reads give ~6 photos of each robot from this match. For each unread window, Jev picks the matching robot or says "unsure".
