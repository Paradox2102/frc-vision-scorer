Static-element zones — block robot false-positives

Tick Draw zones, then drag a box on the map around a field element that gets misdetected as a robot (e.g. a fuel structure). A detection inside a zone can never start a new robot track — but a real robot that drives in keeps tracking. Zones are in field coordinates, so one box covers every camera. Remember to Save.

    Camera view exclusion masks — screen out background false-positives

    Tick Draw exclusion masks, then drag a box on the camera view (Broadcast frame) to block out background regions. Detections inside these regions are completely ignored. Remember to Save masks.
