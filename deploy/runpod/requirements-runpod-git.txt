# Installed AFTER requirements-runpod.txt with
#   SAM2_BUILD_CUDA=0 uv pip install --no-deps --no-build-isolation -r requirements-runpod-git.txt
# --no-deps: sam3 declares numpy<2 (runs fine on 2.3.5, as locally) and every
#   real runtime dep is pinned in requirements-runpod.txt.
# --no-build-isolation: sam2's build-system requires torch; without this uv
#   would download a second (non-cu128) torch into the build sandbox.
# SAM2_BUILD_CUDA=0: skip the optional connected-components CUDA extension
#   (sam2 falls back to its Python path; only used when tracking_backend=sam2).
# Commits pinned in pyproject.toml. The sam2 distribution is named "SAM-2".
