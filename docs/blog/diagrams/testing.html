How we know if a change helped

Everything is scored against robots a human tracked by hand, not against the pipeline's own opinion.
1 · Ground truth

Hand-track every robot

23 robots

4 matches · 4 events · 2 seasons

  • Hold the mouse on one robot at 0.25× speed; let go to hand off to a corner camera
  • Hold Shift when it's hidden: marked as a guess
2 · Score

Compare every 0.25 s

≤ 1 m

to count as the same robot

  • Was the robot tracked?
  • Right team, wrong team, or no team?
  • Seconds of mis-ID, position error
3 · Decide

A/B on all 4 matches

× 2 runs

each arm, because identical runs differ

  • Labels swing ±5 pts between identical runs
  • A change ships only if it beats that noise and no match gets worse
Claude's role: judge and teacher, never in the live pipeline

Claude Code ran as a blind judge on the same crops and track windows the pipeline saw, and was checked against the hand ground truth. It showed what was possible (and how), calibrated a cheap automatic auditor, and labelled the gold sets our own small models were trained and tested on.
